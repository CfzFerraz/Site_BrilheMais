# Site Brilhe Mais Descalvado

Site institucional responsivo desenvolvido para a **Brilhe Mais Descalvado**.

## Visão geral

Aplicação web estática construída com HTML5, CSS3 e JavaScript puro. O site apresenta a empresa, categorias de produtos, duas unidades em Descalvado/SP, galeria de imagens, horários, endereços e canais de contato.

## Funcionalidades

- Landing page institucional.
- Navegação por âncoras.
- Menu responsivo para dispositivos móveis.
- Header que aparece após a rolagem.
- Animações de entrada dos elementos.
- Rolagem suave entre seções.
- Botão de voltar ao topo.
- Seção de produtos/categorias.
- Seção institucional da empresa.
- Galeria das duas lojas.
- Dados completos das duas unidades.
- Links para Google Maps.
- Links diretos para WhatsApp.
- Modal para escolha da loja antes de abrir o WhatsApp.
- Links para Instagram e Facebook.
- Layout responsivo para desktop, tablet e celular.

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
- Font Awesome

## Seções da página

### Hero
Apresenta a proposta da Brilhe Mais, chamada principal, descrição, acesso ao WhatsApp e acesso às lojas.

### Produtos
Apresenta Perfumaria, Maquiagem, Cuidados com a pele, Cabelos, Esmaltes e Acessórios.

### Sobre
Apresenta a empresa, sua proposta, variedade, marcas, atendimento e presença em duas unidades.

### Galeria
Apresenta fotos das unidades e de seus ambientes.

### Contato
Apresenta as duas lojas com telefone, WhatsApp, endereço, CEP, horários, Google Maps e WhatsApp.

## Responsividade

O projeto possui regras específicas para telas de até 1200px, 992px, 768px e 480px.

## JavaScript

O arquivo js/script.js controla menu mobile, header durante a rolagem, botão voltar ao topo, animações, navegação ativa, scroll suave e modal de WhatsApp.

## Como executar

O projeto não possui backend ou dependências de Node.js. Basta abrir index.html em um navegador moderno. Para desenvolvimento, pode ser utilizado o Live Server do Visual Studio Code.

## Personalização

Edite os textos no index.html, substitua as imagens da pasta Img, atualize telefones, WhatsApp, endereços, Google Maps, horários e redes sociais. As cores podem ser alteradas no style.css.

## Organização

- index.html — estrutura e conteúdo.
- css/style.css — estilos principais.
- css/responsive.css — responsividade.
- js/script.js — interações.
- Img/ — imagens e identidade visual.
